The Plugin Release!

The Plugin Panel Release and Halloween/Fall DLC are live! Downloads are ready!

📢 Greetings again MH2 Creators,

• 🎉 We are so very delighted to announce that the MakeHuman 2 second major expansion/patch is live! The Plugin Panel patch is now ready to be downloaded. This expansion, like the original MH2, is completely free to use and create with. As always, our software is AGPL, and all of our content is CC0 and CC-BY with respect to the original creators. Please note we are still in an ongoing open alpha state at present (though highly polished); all feedback and bug finding is highly encouraged and so very helpful!

• ⚡ The original version along with the legacy (final alpha release) and of course the fantasy version of MakeHuman 2 will remain available for download for the foreseeable future! The version you choose is entirely up to you. Linux is also available via the download options in all available versions.

• ⚠️ The Plugin Panel expansion is mostly the same as the current one; however, it unlocks all the newly available features also. To avoid any chance of losing your personal work, always backup before downloading/updating new versions.

• 📝 The most current patch notes can be found below. Briefly, for the sake of explanation, the major difference between the current or Fantasy versions and the plugin release is the addition of a Plugin Panel. This release also includes working examples of both official plugins and community extension-style add-ons.

🎬 Behind the Scenes: We are still actively developing all-new features behind closed doors. If you want to follow our raw development logs, see what we are working on next, or directly support our tiny team’s open-source efforts, check out our community page on Patreon! Also, note there are numerous free downloads both available and upcoming simply for being a free community member. News, teasers, links, and more will be available.

💬 Also Note: We hear the thoughts and opinions of the community. We see all of your suggestions and requests. Do not be bashful; we love to see this! :D However, do keep in mind that not all can ever be honored by us. That said, the community itself may also see and respond to suggestions and share requests.

• 🛠️ As always, the code is available on GitHub as source, and feedback is welcome at any time.

• 🎃 🍁 Halloween/Fall Season DLC is available at this time. There is a completely free content pack to download, and a Patreon one available also.

• 👥 Feel free to join us on Discord and make your thoughts and observations known! We love to see and hear from you all!

• 🎨 🖼️ Please feel welcome to share your art with us on Tumblr with #Makehuman2, and on Discord in the showcase channel. Please also feel free to share your new plugins/add-ons, etc.

• 👀 Also note that the Prop Panel plugin is actively being worked on, and should be available by the end of the year, along with another seasonal DLC. Stay tuned for more news & information to come soon!

The October 2026 Plugin Panel Release Patch/Changenotes:

✨ New Features:

• The Plugin Panel: This opens up via the dropdown menu and will allow any installed add-on to be loaded. (Endpoints to draw one’s own stuff [pre/post paint] & a mechanism for easy connection [load/unload] of plugins). A tutorial example can be found on GitHub.

• Included Plugins: Added both as working examples and to bring additional functionality such as camera controls, lighting tools, an outfit saver, asset purging, and more. (Docking is mostly available for ease of space/usage). See below for an itemized list of inclusions.

• Enhanced Downloader Page: Fully enhanced downloader page allowing multiple asset downloading and thumbnail pre-caching to improve browsing.

• Scalp Helper: Added to the body helper in vertex assignment (for MC2 & Make Apparel functionality at present).

• Alpha Masks: Alpha masks have been added—recoloring of eyes, for example, is now possible using alpha masks.

• Play Timer: A new play timer to announce when you have been creating for preferred durations.

• Skeleton Reduction: Added support for skeleton reduction used for the fantasy skeleton (e.g., to only have a fishtail).

🐞 Bugfixes:

• Breast Region Weights: Fixed and improved the weights in the breast region.

• Normalizing Names: Created normalizing names changed to deal better with Linux and Windows (case dependency / case independency).

• LogLine Crash: Fixed the file helper logLine crash.

• Exporter Parameters: Resolved an object exporter error where it had the wrong number of parameters.

• File Pathing: Fixed file pathing issues causing texture loading problems.

✓ General Quality of Life Improvements:

• Favorites Saving: Save favorites is now available in the asset downloader.

• Scroll Bars: Scroll bars are now available where window size in pop-ups is an issue.

• Make Apparel: More improvements in Make Clothes leading to its new incarnation of Make Apparel (more coming soon for this too).

• Rigid Support: Solid (rigid) handheld support viability. This allows for better use and creation of non-deforming assets.

• Rescan Options: Added rescan options in multiple areas such as the skybox and floor folders, and sorting entries.

• Empty Basemesh: An empty basemesh is now possible (clothes deleting all vertices).

🔌 Our Included Plugins in the Current Release

(Please note all add-ons are a WIP—however, they are highly functional. Find and enable these as you see fit in the dropdown menu under Settings -> Community Plugins)

Plugin Name Description
MH2 Asset Purge This simple and handy tool will allow you to easily cleanup all of your unwanted downloads and creations taking up space. The deleted assets will go to the trash can, allowing you to recall any mistaken removals.
MH2 Camera Controls This necessary tool allows one to adjust the camera settings with the click of a mouse to all available presets. It also allows for filters, box zoom, and overlays.
Make Outfit Making an outfit was always bound to a character—this should likely not be so, which is why we have designed Make Outfit. This easy-to-navigate add-on will allow one to save presets of outfits to attach on the fly to any character they see fit.
Make Note Though a truly simple add-on, this may prove essential in one’s workflow once implemented. Make Note allows one to take notes on the fly and post them alongside their model in a MakeHuman 2 project. You can also attach images of your current muse. These notes can be saved and referred to again.
MH2 Make Lighting Presets Lighting is fun and it should be celebrated as such. Why hide its truly powerful abilities when one can put them right on their screen display? This plugin harnesses what the MH2 engine is capable of in one more way—by unleashing visual effects on the screen and your model!
Make Story A work in progress, but very useful all the same. Make Story allows you to create a backstory, name, career, zodiac assignment (birthday), era, and so much more for the character you create as a way of fleshing it out and making it truly unique. One can have a lot of fun with this. Manual and random entry choices are available at present.
