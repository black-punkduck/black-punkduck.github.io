The Skeleton

This context provides the possibility to add a skeleton or rig to the character.

MakeHuman works with an own standard skeleton which is always present. So even without a skeleton it is possible to pose or animate the character. Nevertheless for an export into another system a skeleton is needed.

A skeleton can only be used once and can be replaced by another skeleton.

The currently selected skeleton is marked with a yellow frame. A green frame means, that the skeleton is used.

Change Skeleton Draw Mode

To activate diamond draw mode for skeleton, simply activate it with the menu. Default is a draw mode using lines.

The colors indicate the mode

  • red: no skeleton is applied and internal skeleton is used
  • blue: a skeleton is applied
  • orange: internal skeleton is used in pose mode

Filtering

As long as tags are provided, skeletons can be filtered in different ways. Skeletons with no tags are always shown. These are the possibilities to filter on the left side:
  • By expanding the item Skeleton, then select a type.

  • By using a text filter, the text filter works on all tags presented in the Tags field after a skeleton is selected.

Hint: If the program shows too many items on right side, it is possible to supply a skeleton with extra tags, these tags are then used instead of the tags provided in the skeleton files.

Loading

To load skeleton, select it from the right column with a single click. Now the information is displayed on left side. To put it on the character, press the checkmark button on the right side. A double click on an unselected skeleton will load it as well.

Drop Skeleton

It is possible to drop the skeleton or simply select another skeleton and replace old one.

Change Information

Select a skeleton before. Press to open asset editor.

You can now change the information:
  • takes a screenshot to be used as a thumbnail. Best to switch off skybox with and use a one-colored background. Under "Settings" change light and scene and select a background color with contrast. It has to be done in skeleton view before. We also recommend diamond draw mode.
  • If you want to use own tags, you can either copy tags to tag editor and change the tags there or create new ones by using the standard tags (recommended for filtering).
