9.1.12 Code of opengl/light.py

opengl/light provides all methods to deal with openGL light settings. The file only contains 1 class:
  • Light

Class Light

This class is used to create all light effects used by shaders in openGL

Variables

These variables are all preset by __init__.
namedescription
glob reference to global object.
shaderInit reference to global shader initialization object.
shaders List of all shaders.
phong references phong shader.
pbr references pbr shader.
toon references toon shader.
min_coords minimal values of the scene in units as a list.
max_coords maximal values of the scene in units as a list.
glclearcolor Color as QVector4D to clear openGL
ambientLight ambientLight as QVector4D
lightWeight lightWeight as QVector3D, x is luminance, y is focus
blinn Phong shading, boolean, true if mode blinn is used.
skybox Determines if skybox is used.
skyboxname Name of the skybox.
lights List of 3 dictionaries with lights, each one represented as position, volume (color), intensity and type (directional or point).
