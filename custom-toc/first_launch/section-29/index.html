The Fantasy Base Mesh

The New Fantasy Base Mesh release is July 25 2026!

This release is a long time coming, as way back a couple years ago, our makehuman 1 forum members voted that
they wanted a mermaid more than anything else for the first fantasy mesh to work with. It could not be a more happy
occasion that this mesh is available now-complete with skeleton and matching helpers for Makeclothes 2! This base, after
the robot mesh is the second of the new base mesh types as proof of concept in the new Makehuman 2.

Please note:

  • This patch is in a mostly working alpha state, however bugs are present. Please feel to report any found bugs on
    steam, discord or the github!

Selection of the Fantasy Mesh:

  • From the loading screen you will see now by default 3 working base mesh types, the robot, hm08, and the
    fantasy. Once selected you can load this as the choice base mesh to work with in a session.

Working with the Fantasy Mesh:

  • Once you have your fantasy version mesh on the screen, you will find this mesh will work in a very similar manner
    as the hm08. In fact you will also find that the fantasy mesh is mostly backwards compatible with the existing assets
    and previous system. Downloading for instance clothing or hair should map right to this mesh the same way it will for the
    hm08!

The unique aspects of the Fantasy vs HM08:

  • As you move to the other panels, you will start to see the major difference in this mesh. The fantasy mesh will allow you to
    attach the new fantasy styled skeleton-thus allowing not just the use of assorted fantasy style body parts in addition to
    normal human body parts but also the manipulation of these parts!

  • At present the body parts are attached using the clothing panel.

  • Looking at the modeling tab you now see a new heading called extra, in this panel you can use sliders corresponding to the
    new body parts such as attached tail or wings. The manipulation of these will only be noticable whilst the model has the
    corresponding attachment in use.
